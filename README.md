# Partnership

This repository contains the development of the **Partnership** platform, which is currently being developed as part of our internship.

## About the Project

Partnership is a web-based application that helps manage users, resellers, referrals, and business operations through a secure role-based system. The platform is designed to provide a simple, efficient, and user-friendly experience for different types of users.

## Features

- Role-based authentication
- Admin, Reseller, and User dashboards
- User & reseller management
- Profile management
- Referral management
- Responsive web interface

## Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap
